STUDENT TASK MANAGEMENT SYSTEM USING SCRUM

1.PROJECT OVERVIEW
Student Task Management is a web-based application developed to help students organize and manage their academic tasks efficiently. The application allows students to maintain their tasks, manage deadlines, set priorities, and track task progress. It is developed using HTML, CSS, and JavaScript.

2.PRODUCT GOAL
The main goal of this project is to provide students with a simple and user-friendly application to organize academic activities and complete their tasks on time.

3.PRODUCT BACKLOG
PB-01: Design the landing page.
PB-02: Develop the main task management interface.
PB-03: Implement the feature to add new tasks.
PB-04: Implement the feature to edit existing tasks.
PB-05: Implement the feature to delete tasks.
PB-06: Add task deadlines and priority levels.
PB-07: Provide task status tracking.
PB-08: Save task details using browser local storage.
PB-09: Display task progress and summary information.
PB-10: Test the application and improve the user interface.

4.SPRINT PLAN

SPRINT 1: INTERFACE DEVELOPMENT
Goal: To develop the basic structure and interface of the application.
Activities:
  Design the landing page.
  Create the main application page.
  Develop the basic layout and navigation.
  
SPRINT 2: TASK MANAGEMENT
Goal: To implement the main task management operations.
Activities:
     Add new tasks.
     Edit existing task details.
     Delete unwanted tasks.
     Display tasks in the application.

SPRINT 3: PROGRESS TRACKING
Goal: To help students monitor their academic progress.
Activities:
     Update task status.
     Manage deadlines and priorities.
     Display task counts and progress.
     Store task information using browser local storage.

SPRINT 4: TESTING AND IMPROVEMENTS
Goal: To test the application and prepare it for submission.
Activities:
     Test the main task operations.
     Check whether task data is saved correctly. 
     Improve the interface and usability.
     Identify and fix errors.
     
5.SPRINT REVIEW
The Sprint Review is used to evaluate the developed features and check whether they meet the project requirements. The application should be tested for adding, editing, deleting, and updating tasks. Data persistence should also be checked by refreshing the browser. The test results should be recorded after performing the actual tests.

6.SPRINT RETROSPECTIVE
The Sprint Retrospective helps identify what went well during development and what can be improved. It allows the development process to be evaluated and helps determine actions for improving the application's quality and usability in future iterations.

7.USE OF GITHUB
GitHub is used to store the project source code and maintain a history of code changes through commits. The Product Backlog and Sprint Plan describe how the development work is divided into smaller activities. These records help explain the planning and iterative development approach used in the project.

8.TECHNOLOGY STACK
HTML is used to create the structure of the web pages. CSS is used to design the user interface and improve its appearance. JavaScript is used to implement task management operations and user interactions. Browser local storage is used to retain task information, while GitHub is used for source code management.

9.CONCLUSION
The Student Task Management project demonstrates how Scrum concepts can be applied to organize software development into smaller stages. Product Backlog preparation, Sprint planning, development, testing, review, and retrospective activities provide a systematic approach to building and improving the application
